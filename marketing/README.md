# Web comercial de Reales Ideales

Ruta pública prevista: https://afelex.github.io/Reales-Ideales/marketing/

Esta carpeta es independiente del juego. Edita `index.html`, `styles.css` y `app.js`. `media/` contiene las imágenes comerciales aprobadas, no reemplazarlas con arte inventado. La caja original está dividida en seis fragmentos binarios debido al límite del conector de subida; se reconstruye sin pérdidas en app.js. Las figuras JPG con fondo blanco se recortan en el navegador mediante transparencia de fondo conectado a bordes. Los vídeos originales se sirven desde assets/ del juego. Mantener la demo actual y distinguir funciones previstas (multijugador online, premios y puntos persistentes) de las disponibles. No publicar precios ni disponibilidad sin confirmación. Para colaboradores: trabajar en esta carpeta y crear un PR, sin modificar el juego.
